Hướng dẫn cài Betagon Center

Tải Betagon Center, mở SketchUp và cài file .rbz thông qua Extension Manager. Sau khi cài xong, dùng Center để tải và cập nhật các plugin Betagon.

Window → Extension Manager → Install Extension → Chọn file Betagon Center .RBZ

Nếu đang dùng plugin cũ, nên tắt SketchUp rồi gỡ bản cũ trước khi cài lại qua Betagon Center.

1
Tải Betagon Center

Bấm nút tải trên web và lưu file về máy.

2
Mở SketchUp

Vào Window → Extension Manager.

3
Install Extension

Chọn file Betagon Center .RBZ vừa tải.

4
Mở Betagon Center

Vào toolbar/menu Betagon để mở Center.

5
Cài plugin trong Center

Chọn plugin cần dùng và bấm cài/cập nhật trong Center.
